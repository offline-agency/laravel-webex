# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | yes |
| 1.x | no |

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting ([Security → Report a vulnerability](https://github.com/offline-agency/laravel-webex/security/advisories/new)) or email <info@offlineagency.it> (the contact published on the [Offline Agency GitHub organization](https://github.com/offline-agency)) with a description, the affected versions and, if possible, a proof of concept. Do not include real Webex tokens.
